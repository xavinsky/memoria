### Recherche globale (tout le web)

:::cards
- [Google Dataset Search](https://datasetsearch.research.google.com/) : seul vrai moteur GLOBAL : indexe les datasets de tout le web, tous domaines, toutes sources
:::

### Recherche fédérée (agrège des milliers de dépôts, pas le web entier)

:::cards
- [DataCite Commons](https://commons.datacite.org/) : agrège les datasets avec DOI de milliers de dépôts dans le monde (Zenodo, Figshare, dépôts universitaires...)
- [OpenAIRE Explore](https://explore.openaire.eu/) : agrège recherche & données de milliers de sources, financé UE mais portée internationale
:::

### Recherche au sein d'un catalogue (leur propre univers de données)

:::cards
- [Zenodo](https://zenodo.org/) : dépôt de données de recherche multidisciplinaire (CERN / OpenAIRE) — recherche limitée à SON propre catalogue
- [Kaggle Datasets](https://www.kaggle.com/datasets) : catalogue de datasets réels, tous domaines — recherche limitée à SON propre catalogue
:::

:::cards
- [Our World in Data](https://ourworldindata.org/) : indicateurs mondiaux : santé, énergie, climat, économie...
- [World Bank Open Data](https://data.worldbank.org/) : développement & macroéconomie, tous pays
- [Eurostat](https://ec.europa.eu/eurostat/data/database) : statistiques officielles de l'Union européenne
- [data.europa.eu](https://data.europa.eu/en) : portail open data de l'UE
- [OECD Data](https://data.oecd.org/) : statistiques des pays de l'OCDE
- [UN Data](https://data.un.org/) : bases de données des agences de l'ONU
- [WHO Global Health Observatory](https://www.who.int/data/gho) : données de santé mondiale
- [NASA Earthdata](https://www.earthdata.nasa.gov/) : sciences de la Terre & climat
- [NOAA](https://www.ncei.noaa.gov/) : données climatiques & océaniques
- [Hugging Face Datasets](https://huggingface.co/datasets) : catalogue ML/NLP prêt à charger
- [Awesome Public Datasets](https://github.com/awesomedata/awesome-public-datasets) : liste organisée par domaine (GitHub)
- [Public APIs](https://github.com/public-apis/public-apis) : liste organisée d'APIs publiques (GitHub)
:::

### Musique

:::cards
- [MusicBrainz](https://musicbrainz.org/) : base collaborative ouverte : artistes, albums, morceaux (API libre)
- [Discogs](https://www.discogs.com/developers) : base de données de sorties musicales (vinyles, albums), API
- [Million Song Dataset](http://millionsongdataset.com/) : 1M de morceaux avec métadonnées & features audio, référence en MIR (Music Information Retrieval)
:::

### Cinéma

:::cards
- [TMDb (The Movie Database)](https://www.themoviedb.org/documentation/api) : films, acteurs, notes — API ouverte très utilisée
- [OMDb API](https://www.omdbapi.com/) : données façon IMDb (films, séries) via API simple
:::

### Peinture & Arts visuels

:::cards
- [The Met Open Access](https://www.metmuseum.org/art/collection) : collection complète du musée en open data, images HD incluses
- [Rijksmuseum API](https://data.rijksmuseum.nl/object-metadata/api/) : collection du musée néerlandais, très utilisée pour la vision par ordinateur
- [Art Institute of Chicago API](https://api.artic.edu/docs/) : collection ouverte avec images & métadonnées
- [Wikidata / Wikimedia Commons](https://www.wikidata.org/) : métadonnées & images libres d'œuvres d'art de musées du monde entier
:::

### Littérature

:::cards
- [Project Gutenberg](https://www.gutenberg.org/) : 70 000+ livres du domaine public, texte brut — référence pour le NLP
- [Open Library](https://openlibrary.org/developers/api) : métadonnées de millions de livres (Internet Archive), API ouverte
:::
