## Variance Inflation Factor (VIF)
Formule / Syntaxe:
```
$$VIF(X_k) = \dfrac{1}{1-R_k^2}$$
from statsmodels.stats.outliers_influence import variance_inflation_factor as vif
[**vif**(X_scaled.values, i) for i in range(X_scaled.shape[1])]
```
Params:
```
$R_k^2$ : R² obtenu en régressant $X_k$ sur toutes les autres features
X_scaled : features standardisées (cf. Standardiser les features avant régression)
```
Explication: détecte la multicolinéarité multivariée (contrairement à la matrice de corrélation, limitée aux paires de variables) — règle empirique : VIF ≥ 10 signale une feature redondante avec les autres, candidate à retirer ou combiner ; s'applique aussi bien à une régression linéaire (OLS) que logistique
